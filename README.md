# VEHISAFE 2.0 Firmware

Embedded firmware for the Vehisafe vehicle tracking system.

## Overview
This project contains the firmware used in the Vehisafe VTS device for vehicle monitoring and control.

## Features
- GPS tracking
- GSM communication
- SMS command handling
- Panic button handling
- EEPROM data storage
- Device health monitoring

## Hardware
- Microcontroller platform
- GSM module
- GPS module
- EEPROM
- Serial communication interfaces
