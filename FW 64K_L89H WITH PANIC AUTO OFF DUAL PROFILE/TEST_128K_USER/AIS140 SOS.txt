# AIS140 SOS BUTTON IMPLEMENTATION STRATEGY
# DO NOT create new variables, functions, strings or anything that consumes memory

## OVERVIEW
When SOS button is pressed, the device must send BOTH:
1. PVT packet with EA (Emergency Alert) type and AlertID 10
2. EPB packet (separate format) to the same IP (secondary IP to be added later)

## TRANSMISSION RULES

### PHASE 1: SOS PRESSED (Emergency Active)
- **Trigger**: SOS button press → INTP3 interrupt → PANIC_ALERT = ON
- **Duration**: 30 seconds (configurable via PANIC_TIME counter)
- **Interval**: Send packets every 5 seconds

### Packets to send every 5 seconds:
| Packet | Header | PacketType | AlertID | Destination |
|--------|--------|------------|---------|-------------|
| PVT | $PVT | EA | 10 | Primary IP |
| EPB | $EPB | EMR | N/A | Same IP (secondary later) |

### PHASE 2: Emergency Timeout (After 30 seconds)
- **Trigger**: PANIC_TIME reaches configured threshold (30000 ms / 30 seconds)
- **Action**: Send ONE final packet to clear emergency state

### Packets to send at timeout:
| Packet | Header | PacketType | AlertID | Destination |
|--------|--------|------------|---------|-------------|
| PVT | $PVT | EA | 11 | Primary IP |

**NOTE**: AlertID 11 = Emergency State OFF (from Table 4B)

### PHASE 3: Normal Operation (After timeout)
- **Stop sending EPB packets completely**
- **Revert PVT to normal**: PacketType = NR, AlertID = 01
- **Continue normal transmission interval** (40 seconds or configured)

The problem is that **IGNITION_SW pin (P6_bit.no3) is FLOATING** - it doesn't have pull-up/pull-down configured.

## **Why This Happens**

When you remove 3.3V:
```
With 3.3V connected → P6_bit.no3 = HIGH (OPEN)
Remove 3.3V → P6_bit.no3 = FLOATING (stays HIGH due to capacitance/no pull-down)
```

**The pin needs to be pulled to GND when disconnected!**

## **What This Fixes**

**Before (No Pull-Up):**
```
3.3V connected → P6_bit.no3 = HIGH (reads OPEN correctly)
3.3V removed   → P6_bit.no3 = FLOATING → stays HIGH or random
                 Result: Reads CLOSE = TRUE (stuck ON) ❌
```

**After (With Pull-Up):**
```
3.3V connected → P6_bit.no3 = HIGH → goes LOW (reads CLOSE/ON) ✓
3.3V removed   → P6_bit.no3 = PULLED HIGH (reads OPEN/OFF) ✓
                 Result: Correctly detects state ✅
```
